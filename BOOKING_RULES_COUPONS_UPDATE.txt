BOOKING / RULES / COUPONS UPDATE

1. Booking Add Booking popup now contains:
   S PNR, Client ID, Passenger ID, Passenger Name, Sector, Booking Type,
   Travel Type, Airline Name, Airline Type, Airline PNR, Net Amount,
   Travel Start Date, Travel End Date, Booking Date.
2. All booking fields are compulsory.
3. Airline Name uses a datalist: type to filter or select from the supplied airline list.
   Free-typed airlines are accepted and use ANY AIRLINE rules when available.
4. Airline Type is a fixed select: Economy Class, Premium Class,
   Business Class, ANY CLASS.
5. Booking Net Amount is calculated from the entered amount using the matching Rules discount.
6. Passenger ID in the Booking table is clickable and opens the complete booking popup.
   Save and Delete are available in the popup; the old Actions column was removed.
7. Horizontal booking scrollbar is fixed at the bottom of the viewport.
8. Rules page now uses Airline Name + Airline Type + Discount Percentage + Status.
9. Coupon points = Booking Net Amount / 100.
10. Coupon status is PENDING before Travel Start Date and AVAILABLE on/after Travel Start Date.
11. Coupon Amount = Available Points / 10. Before availability it is ₹0.00.
12. Redeem Coupon uses Passenger ID, auto-fills details, consumes available coupon points,
    subtracts Coupon Amount from Booking Net Amount, and records the redemption.
13. Reverse Coupon uses Passenger ID, restores Coupon Amount x 10 points and adds Coupon Amount
    back to Booking Net Amount.
