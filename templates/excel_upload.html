The Status column is required and must be either Confirmed or Cancelled. A cancelled booking does not earn a coupon, and any existing earned coupon is automatically reversed. A Client ID not yet registered is created automatically using that ID as the client name. Matching coupon rules are applied to Net Amount. Confirmed imported passengers automatically earn a coupon and ledger entry; it is released when the Travel Start Date has passed, otherwise it stays pending.
